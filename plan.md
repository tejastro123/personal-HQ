# MEGA PROMPT — BUILD A PREMIUM INTERACTIVE PERSONAL PORTFOLIO PLATFORM

Build a complete, production-quality, fully responsive personal portfolio website that combines:

1. A premium SaaS-style landing page
2. A personal developer/researcher portfolio
3. An interactive project showcase
4. An interactive choropleth world map
5. A link-in-bio experience
6. An interactive 3D physics playground
7. About, skills, testimonials, pricing/services, and contact sections
8. Strong conversion-focused CTAs throughout

The website should feel like a **premium personal digital headquarters**, not a collection of unrelated templates.

The overall design should combine:

* Modern SaaS aesthetics
* Editorial portfolio design
* Apple-level minimalism
* Premium technology/startup visual language
* Subtle glassmorphism
* Strong typography
* Excellent spacing
* Smooth animations
* Interactive data visualization
* Dark/light theme support
* Responsive mobile-first design
* High accessibility
* Extremely polished micro-interactions

The final result should look like something a highly skilled designer/developer/researcher would use as their personal flagship website.
